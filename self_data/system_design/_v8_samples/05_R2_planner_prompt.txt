- If `needs: starting AND remaining` (no fill read at all in R1): emit ONE journey sample at the earliest unsampled retrieval moment AND one dense window over the dispense action; OR a journey sample at retrieval + a journey sample at the put-back / last-sighting frame.
- If `needs: remaining` (R1 has starting only): a dense window catching the END of the dispense action, OR a journey sample at put-back / final shelf view.
- If `needs: starting` (R1 has derivative only): an EARLIER unsampled window where the package is first picked up / pre-dispense.
- If `needs: any fill view` (R1 has only derivative, no package was seen): any unsampled visibility burst — earliest preferred.
